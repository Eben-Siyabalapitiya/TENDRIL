Videos were converted from iPhone .MOV (HEVC) to mp4 so browsers can play them:

```bash
ffmpeg -i IMG_XXXX.MOV -vf "scale=-2:720,fps=30" -c:v libx264 -crf 25 -pix_fmt yuv420p -movflags +faststart out.mp4
```
