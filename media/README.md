# Media

Drop files in here with these exact names and the site picks them up.
Anything missing just shows a placeholder box instead, so the page never breaks.

| file | where it shows |
| --- | --- |
| `demo.mp4` | the main video in the hero |
| `poster.jpg` | the still frame shown before the video plays |
| `log-generator.jpg` | build log 01 |
| `log-channel.jpg` | build log 02 |
| `log-break.jpg` | build log 03, the arm that snapped at the base |
| `log-fillet.jpg` | build log 04, the bigger fillet |
| `log-rings.jpg` | build log 05, the finger rings |
| `log-servo.jpg` | build log 06 |
| `gallery-1.jpg` … `gallery-4.jpg` | the grid under the build log |

Photos are shown at 4:3, cropped to fill. Landscape works best.
